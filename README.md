# 大烧货LINK Engine（PC 端）

**大烧货LINK（DSHLink）** —— 用华为手表通过 Wi-Fi 局域网遥控 PC 上的 **DeepSeek Harness（DSH）** 编程助手。

手表端 App 通过局域网 TCP 向 PC 端引擎发送控制指令，引擎将指令转换为键鼠操作，发送给处于前台的 DeepSeek Harness 桌面应用；同时引擎读取 DSH 的会话投影缓存，把 **项目进度、五色状态灯、会话列表与历史对话** 实时同步到手表，状态变化时手表震动提醒。

> 本仓库仅发布 Windows 可执行文件，**不含任何源码**（PC 端与鸿蒙手表端源码均不公开）。

## 系统要求

- Windows 10 / 11 x64
- PC 已安装 DeepSeek Harness 桌面版并登录
- 手表与 PC 处于同一局域网（路由器需关闭 AP 隔离）

## 快速开始

1. 下载 `DSHLinkEngine.exe` 并运行（单文件，无需安装）。
2. 首次运行允许 Windows 防火墙（勾选「专用网络」）。
3. 主界面记下 **配对码**（可点击复制）、**本机 IP**，TCP 端口默认 **9537**。
4. 手表端安装「大烧货LINK」App（HarmonyOS），输入 PC 的 IP 与配对码完成配对。
5. 打开 DeepSeek Harness 进入任意会话，保证其窗口在前台（引擎发送按键前也会自动聚焦）。
6. 程序驻留系统托盘，双击托盘图标恢复窗口。

## 端口与协议

| 端口 | 协议 | 用途 |
|---|---|---|
| TCP 9537 | TCP | 控制指令下发与状态同步 |
| UDP 9538 | UDP | 设备发现（`pc_beacon` 广播） |

配对：6 位配对码认证（可自动生成 / 手动指定）。

## 主要功能

- **遥控键鼠**：鼠标移动 / 点击 / 滚轮、单键与组合键、剪贴板粘贴（中文兼容）
- **快捷命令 6 键**：提交（Enter）/ 自定义上（Esc）/ 新任务（Ctrl+N）/ 命令（/）/ 自定义下（Ctrl+,）/ 回退（Ctrl+Z）
- **目标 / 计划 / 批准**：`/goal`、`/plan`、批准=Enter
- **摇杆四方向 + Agent 键 A1–A6**：全部按键映射可在引擎「设置」中自定义
- **DSH 状态监控**：空闲 / 思考中 / 已完成 / 等待回答 / 出错 五态状态灯
- **状态变化震动提醒**：等待回答=双短震、出错=长震、已完成=轻震（手表端可开关）
- **项目进度下钻**：项目卡片 → 会话列表 → 历史对话，含轮次数 / 模型名 / 置顶 / 已归档
- **上下文占用率**：彩色占用条（<60% 绿 / 60–84% 橙 / ≥85% 红）
